Required fields and input scope

Fields: tenant, event_id, timestamp with timezone, principal, resource, action, public_access, unusual_region, large_read. Indicators must be integers 0 or 1. JSON imports use an object containing an events array. Maximum: 16 MiB / 10000 records.

This version accepts normalized exports. Provider-specific formats require an adapter or conversion to this schema; direct cloud connectors are not configured.

ANALYST WORKFLOW

How to use this workspace

  1. Import records. Upload your normalized logs and, optionally, a permission policy.
  2. Select an incident. Inspect the identity, resource, event timeline and score contributions.
  3. Record an assessment. Choose expected activity, more evidence needed, or suspected threat, with your rationale.
  4. Investigate or respond. Add evidence, or preview and approve a policy-permitted response. Record any external action and its ticket reference.
  5. Close and export. Close as expected, resolved, or escalated. Export the signed investigation archive.

Scores use a transparent configured profile, not trained AI. Signing uses a local software key. Analyst identity and external action completion are self-asserted. The application does not change cloud resources.
